# SentinelScan

Web3 fraud and compliance scanner. SentinelScan helps users check Web3 projects, wallets and transactions for common risk signals before interacting with them.

**Live demo:** https://web3-fraud-scanner-d-qh0r.bolt.host

## Features

- **Project scanner (URL / Terms of Service):** analyzes a project website or pasted Terms of Service text with an AI backend and lists red flags with a 0-100 risk score.
- **Wallet Scanner:** fetches real on-chain data for a wallet (recent transactions, token holdings, counterparties) and calculates a risk score.
- **Transaction Scanner:** inspects a single transaction and highlights risk signals.
- **Risk explanation:** wallet and transaction results include a plain-language explanation generated by transparent, rule-based logic from the retrieved on-chain data. No AI model is used for this part.

## Supported networks

Ethereum, Base and Arbitrum (via Etherscan API V2), and Solana.

## Tech stack

- React + TypeScript + Vite
- Tailwind CSS
- Supabase Edge Functions (API calls run server-side, keys are never exposed in the browser)
- Etherscan API V2

## Notes and limitations

- Wallet analysis covers recent activity (the latest 100 transactions), not the full wallet history.
- The Recent Scans list on the Dashboard contains sample data for demonstration.
- Risk scores describe likelihood based on observed signals. They are not proof of fraud and not financial advice.
